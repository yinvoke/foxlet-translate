# 小米 14：翻译质量

使用 FLORES-200 devtest 前 200 条、相同 Mozilla 模型与中文参考，按 `wmt22-comet-da × 100` 评分。每个版本、每个语向导出三个独立进程的译文；范围为三次结果的最小值和最大值。

| 方向 | v0.2.0 原生默认路径 | v0.3.0 原生默认路径 / AAR | 新版 − 旧版 |
|---|---:|---:|---:|
| 英→中 | 87.15–87.19 | 87.27 | +0.08～+0.12 |
| 日→英→中 | 86.78–86.82 | 86.71 | −0.10～−0.06 |


差值由未舍入分数计算。两语向 COMET 变化均小于 0.12 分，说明本批语料的整体评分接近，尚不足以证明统计上的质量等价。

v0.2.0 使用 AsyncService 1 worker、batch 1024、无英文前缀表；v0.3.0 使用 BlockingService、batch 512、英文前缀表。两者结果缓存均关闭，比较包含默认参数变化。

- 新版两语向各三次原生导出一致，并与 AAR 的 1 / 2 / 4 线程译文一致。
- 旧版每个语向有两组输出；相较第一轮，后两轮英→中有 5/200 条变化，日→中有 14/200 条变化。
- 旧版与新版之间，英→中有 37–41/200 条、日→中有 36–38/200 条译文不同。
- ML Kit / v0.3.0 的 COMET × 100：英→中 **72.69 / 87.27**，日→中 **68.93 / 86.71**。结果仅适用于本批语料、模型和 ML Kit 端侧 SDK。

## 数据与复核

[原生译文清单](quality-reference/manifest.json)记录构建、模型、语料和 12 个进程的译文指纹；[质量评分](quality-comet-with-reference.json)包含逐条分数和来源链接。

[AAR 原始译文](app-reference/results.json)来自一次未完成性能采集中的 10 个完整进程，仅用于质量评测。[AAR 评分](app-scores.json)保留原报告与脱敏归档的摘要关联。性能结论使用独立的[完整性能报告](../performance/README.md)。

```bash
python3 benchmarks/v0.3.0/mi14/quality/verify.py
```

脚本核对 42 遍输出的来源、哈希、逐条分数均值，以及新版原生 / AAR 一致性。原生导出程序用于质量对照，不提供旧 AAR 的端到端性能结论。
