# v0.1.0：历史性能起点

源码 tag：`v0.1.0`，提交 `d447381b1259a8f101a91390dd8950ad7080c84e`。这是本项目的初版 Android 移植，不是原封不动的 Mozilla/Bergamot 上游。

小米 10 / 骁龙 865 / Android 13。与 v0.2.0 在同一场次配对测试，原始记录集中保存在 [v0.2.0/results.json](../v0.2.0/results.json)，其中 `version = v0.1.0` 的样本就是本版记录，避免复制两份同场次数据。

| 场景 | 首次耗时中位数 | 首遍峰值 RSS 中位数 |

| 英→中，1 worker | 7.208 s | 322.969 MiB |
| 英→中，4 workers | 3.249 s | 947.617 MiB |

英→中 2 workers 有一次 SIGABRT，不能作为完整三轮基线。测试条件、热态表现和限制见 [配对报告](../v0.2.0/README.md)。
