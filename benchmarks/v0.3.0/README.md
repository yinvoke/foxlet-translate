# v0.3.0：性能与质量

本页汇总 v0.3.0 的性能与质量评测。测量对象以各报告记录的源码、模型和二进制指纹为准；发布内容见 [v0.3.0 Release](https://github.com/yinvoke/foxlet-translate/releases/tag/v0.3.0)。

## 结果概览

| 评测 | 结论 | 完整报告 |
|---|---|---|
| 小米 14：v0.2.0 → v0.3.0 原生回归 | 固定八场景、48 个进程通过稳定性与回归检查，同配置性能整体接近 | [性能报告](mi14/performance/README.md) |
| 小米 14：AAR 与 ML Kit | 24 个进程完成；六项指标波动超限，性能仅作参考。72 遍译文均匹配已有质量评分 | [App 与质量报告](mi14/performance/README.md) |
| v0.2.0 → v0.3.0 翻译质量 | 两语向 COMET 接近，部分译文随分句和组批方式变化；新版原生输出与 AAR 一致 | [质量对照](mi14/quality/README.md) |
| 小米 14：v0.1.0 → v0.3.0 默认参数 | 英→中 / 日→中首次速度为初版的 2.02× / 2.12×，峰值 RSS 减少 40.6% / 41.8%；跳过频率门槛且存在不稳定场景，仅作参考 | [初版性能对照](mi14/initial-comparison/README.md) |

质量比较使用 FLORES-200 前 200 条。COMET × 100：英→中为 ML Kit 72.69 / v0.3.0 87.27，日→中为 68.93 / 86.71。结论限于该语料、模型与端侧 SDK。

## 历史默认参数对照

200 行 FLORES-200；速度按 `200 条源文 ÷ 首次耗时中位数` 换算，计时含模型创建与加载；峰值为 native RSS。原始耗时没有改变。

| 设备 / 方向 | v0.2.0 速度 | v0.3.0 参考速度 | 速度倍率 / 提升 | 峰值 RSS |
|---|---:|---:|---:|---:|
| 小米 10 / 英→中 | 42.36 条/秒 | 47.09 条/秒 | 1.11× / +11.2% | 185 → 184 MiB |
| 小米 10 / 日→中 | 19.59 条/秒 | 23.09 条/秒 | 1.18× / +17.9% | 290 → 289 MiB |
| 小米 14 / 英→中 | 63.89 条/秒 | 65.56 条/秒 | 1.03× / +2.6%，不作为明确收益 | 208 → 208 MiB |
| 小米 14 / 日→中 | 28.76 条/秒 | 31.81 条/秒 | 1.11× / +10.6% | 314 → 309 MiB |

v0.2.0 使用 AsyncService 1 worker、batch 1024、无前缀表；v0.3.0 使用 BlockingService、batch 512、源语言前缀表。收益包含默认参数调整。两版使用**相同**配置时性能整体接近，不能把本表归因于新的 GEMM 内核提速。
