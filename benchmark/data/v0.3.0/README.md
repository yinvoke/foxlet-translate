# v0.3.0：与 v0.2.0 的差异

已发布版本，见 [v0.3.0 Release](https://github.com/yinvoke/foxlet-translate/releases/tag/v0.3.0)。本页汇总本版全部评测；原始记录在 [`raw/`](raw/)，机器可读索引见 [`index.json`](index.json)。测量对象以各原始报告记录的源码、模型和二进制指纹为准。

| 与 v0.2.0 相比 | 结论 | 原始数据 |
|---|---|---|
| 小米 14 原生回归 | 固定八场景、48 进程通过稳定性与回归检查，同配置性能整体接近；检查器退出码 `0` | [data/mi14/native/results.json](raw/mi14/native/results.json) |
| 小米 14 翻译质量 | 两语向 COMET 变化均小于 0.12 分；部分译文随分句和组批方式变化 | [data/mi14/quality/comet.json](raw/mi14/quality/comet.json) |
| 默认参数 | 小米 10 英→中 / 日→中首次速度 +11.2% / +17.9%；小米 14 为 +2.6% / +10.6% | [data/mi10](raw/mi10)、[data/mi14/history](raw/mi14/history) |

另有两组不与 v0.2.0 对比的测量：与 Google ML Kit 的 App 对照（24 进程完成，波动超限仅作参考），以及 [v0.1.0 → v0.3.0 默认参数对照](#v010--v030-默认参数对照参考)。

质量比较使用 FLORES-200 前 200 条。COMET × 100：英→中为 ML Kit 72.69 / v0.3.0 87.27，日→中为 68.93 / 86.71。结论限于该语料、模型与端侧 SDK。

## 小米 14：v0.2.0 → v0.3.0 原生回归

小米 14 / 骁龙 8 Gen 3 / Android 16，FLORES-200 前 200 条。固定八场景 × 两版本 × 三轮 AB / BA / AB，每进程三遍，共 **48 个进程、144 遍**。源码、构建、模型、语料及设备指纹见[原始报告](raw/mi14/native/results.json)。

每进程前后核验亮屏、未锁定和 app 焦点；起跑 CPU 2 / 7 频率上限均为 2630400 kHz，电池温度 30.4–30.9°C。耗时和 RSS 波动均在中位数 10% 内，最大 8.74%；固定稳定哈希场景输出未变，检查器返回 `0`。

## 小米 14：翻译质量

FLORES-200 devtest 前 200 条、相同 Mozilla 模型与中文参考，按 `wmt22-comet-da × 100` 评分。每个版本、每个语向导出三个独立进程的译文；范围为三次结果的最小值和最大值。

| 方向 | v0.2.0 原生默认路径 | v0.3.0 原生默认路径 / AAR | 新版 − 旧版 |
|---|---:|---:|---:|
| 英→中 | 87.15–87.19 | 87.27 | +0.08～+0.12 |
| 日→英→中 | 86.78–86.82 | 86.71 | −0.10～−0.06 |

差值由未舍入分数计算。两语向 COMET 变化均小于 0.12 分，说明本批语料的整体评分接近，尚不足以证明统计上的质量等价。

v0.2.0 使用 AsyncService 1 worker、batch 1024、无英文前缀表；v0.3.0 使用 BlockingService、batch 512、英文前缀表。两者结果缓存均关闭，比较包含默认参数变化。

- 新版两语向各三次原生导出一致，并与 AAR 的 1 / 2 / 4 线程译文一致。
- 旧版每个语向有两组输出；相较第一轮，后两轮英→中有 5/200 条变化，日→中有 14/200 条变化。
- 旧版与新版之间，英→中有 37–41/200 条、日→中有 36–38/200 条译文不同。
- ML Kit / v0.3.0 的 COMET × 100：英→中 **72.69 / 87.27**，日→中 **68.93 / 86.71**。

[原生译文清单](raw/mi14/quality/native/manifest.json)记录构建、模型、语料和 12 个进程的译文指纹；[质量评分](raw/mi14/quality/comet.json)包含逐条分数和来源链接。[AAR 原始译文](raw/mi14/quality/app/results.json)来自一次未完成性能采集中的 10 个完整进程，仅用于质量评测；[AAR 评分](raw/mi14/quality/app-scores.json)保留原报告与脱敏归档的摘要关联。

12 个原生导出中只有 6 份译文互不相同（新版两语向的三轮输出各自完全一致，旧版各有两组）。归档按内容保存这 6 份，文件名取 `output_sha256` 前 8 位；每次运行的版本、语向、轮次与哈希仍完整保留在清单中，去重不改变任何字节。

## v0.1.0 → v0.3.0 默认参数对照（参考）

本组测试在系统当前调频状态下运行，两版均不等待频率上限恢复，保留相同场景、交替顺序与进程间隔。**属于描述性性能对照，不作为严格回归基线**，严格检查器退出码为 `2`。

命名口径：项目 README 中的“未优化版本 v0.1.0”指后续专项性能优化之前的对照版本。它已包含 ruy SDOT 内核编译修复和 CPU 指令集检测适配，不代表完全没有优化，也不是未经修改的 Mozilla 上游。

**48/48 个进程、144 遍翻译完成，无进程崩溃。** 默认单线程首次翻译速度为初版的 **2.02×（英→中）/ 2.12×（日→中）**，峰值 RSS 减少 **40.6% / 41.8%**。

| 项目 | 配置 |
|---|---|
| 设备 | 小米 14，骁龙 8 Gen 3，Android 16 |
| 初版 | v0.1.0，`d447381b1259a8f101a91390dd8950ad7080c84e`，本项目初版 Android 移植 |
| 最新版 | 本地 v0.3.0 快照，HEAD `bfc6a08c0aeaa8a679170d517c5c041a83c01834` |
| 构建 | 共用测试入口，arm64-v8a / Release / Android API 28 / NDK 29.0.13113456 |
| 输入 | FLORES-200 前 200 条英文或日文源文；两版共用模型、词表、shortlist 和语料 |
| 场景与重复 | `android-native-v1` 固定八场景 × 两版本 × 三轮；AB / BA / AB；每进程三遍 |
| 调度 | CPU 亲和性 `7c`（CPU 2–6），进程间隔 8 秒，结果缓存关闭 |
| 频率条件 | 显式启用 `--skip-frequency-gate`，两版均跳过起跑频率门槛 |

## 数据与复核

```bash
python3 -B benchmark/data/v0.3.0/verify.py
```

入口依次运行 [`checks/`](checks/) 下的三个脚本：`initial.py` 重放初版对照、`quality.py` 核对译文与评分链路、`native.py` 核对原生与 App 报告及其波动。`checks/test_initial.py` 用合成数据覆盖拒绝逻辑，合成数值不作为性能证据。复核通过只表示归档内部一致，不重跑设备或 COMET 模型，也不把已记录的验收失败改成通过。

采集程序与语料存放在 [`../shared/`](../shared/)，本版使用的别名映射见 [`index.json`](index.json) 的 `collectors` / `corpora`。重新测量见[原生工具](../../../tools/version-bench/README.md)与 [App 工具](../../../tools/app-bench/README.md)。语料署名与许可见 [FLORES 数据出处](../CITATION.md)。
