## 各自默认单线程参数的配对结果

200 行 FLORES-200；速度按 `200 条源文 ÷ 首次耗时中位数` 换算，计时含模型创建与加载；峰值为 native RSS。原始耗时没有改变。

| 设备 / 方向 | v0.2.0 速度 | v0.3.0 参考速度 | 速度倍率 / 提升 | 峰值 RSS |
|---|---:|---:|---:|---:|
| 小米 10 / 英→中 | 42.36 条/秒 | 47.09 条/秒 | 1.11× / +11.2% | 185 → 184 MiB |
| 小米 10 / 日→中 | 19.59 条/秒 | 23.09 条/秒 | 1.18× / +17.9% | 290 → 289 MiB |
| 小米 14 / 英→中 | 63.89 条/秒 | 65.56 条/秒 | 1.03× / +2.6%，不作为明确收益 | 208 → 208 MiB |
| 小米 14 / 日→中 | 28.76 条/秒 | 31.81 条/秒 | 1.11× / +10.6% | 314 → 309 MiB |

v0.2.0 使用 AsyncService 1 worker、batch 1024、无前缀表；v0.3.0 使用 BlockingService、batch 512、源语言前缀表。收益包含默认参数调整。两版使用**相同**配置时性能整体接近，不能把本表归因于新的 GEMM 内核提速。完整验收说明见 [acceptance.md](acceptance.md)。

## 回归基线状态

这些旧报告缺少设备唯一指纹、模型/语料 SHA-256 和机器可读构建参数等字段，**只用于历史趋势，不能补写字段后当成严格基线**。2026-09-09 最初重连后的原生配对因频率门槛超时未起跑；该场 app 三轮因四项耗时波动超限未通过。后续充电后场次已单独完成原生配对并通过检查，新基线见[该场记录](mi14-2026-09-09/charged/README.md)；未覆盖或拼接前次样本。小米 10 需另测。

2026-09-09 已补算当前 AAR 与 ML Kit 的 COMET，并在重连后完成旧版→新版原生默认路径的质量对照。英→中为 87.15–87.19 → 87.27，日→中为 86.78–86.82 → 86.71；默认分句、组批和旧 async 调度会改变部分译文。整体评分接近，不等于逐字不变或统计上的质量等价。
