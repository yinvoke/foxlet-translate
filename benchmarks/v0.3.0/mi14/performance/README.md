# 小米 14：性能评测

小米 14 / 骁龙 8 Gen 3 / Android 16，FLORES-200 前 200 条。原生版本回归通过；AAR 与 ML Kit 的完整对照有六项指标波动超限，仅作性能参考。

## 原生版本回归

v0.2.0 → v0.3.0，固定八场景 × 两版本 × 三轮 AB / BA / AB，每进程三遍，共 **48 个进程、144 遍**。源码、构建、模型、语料及设备指纹见 [原始报告](native-results.json)。

每进程前后核验亮屏、未锁定和 app 焦点；起跑 CPU 2 / 7 频率上限均为 2630400 kHz，电池温度 30.4–30.9°C。耗时和 RSS 波动均在中位数 10% 内，最大 8.74%；固定稳定哈希场景输出未变，检查器返回 `0`。

下表为 **v0.2.0 → v0.3.0**，每行配置相同。首次包含模型加载；热态先取每进程后两遍中位数，再跨进程取中位数。速度为 200 条源文除以耗时，RSS 为首遍 VmHWM。
